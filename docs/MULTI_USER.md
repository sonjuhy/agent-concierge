## 0. 가족 추가하는 법

1. 가족을 Slack 워크스페이스에 초대하고, 프로필 → ⋮ → **멤버 ID 복사**
2. `docs/users.example.yaml` 을 `data/users.yaml` 로 복사해 본인(owner)과 가족(family)을 적고 `systemctl --user restart agent`
3. 가족이 봇에게 DM 으로:
   - `agy 로그인` → 받은 주소에서 Gemini(Google AI Pro) 계정 로그인 → 화면의 **인증 코드**를 DM 으로 보내기
   - `구글 로그인` → 받은 주소에서 로그인 → "확인되지 않은 앱"은 *고급 → 이동* → 마지막 "사이트에 연결할 수 없음" 화면의
     **주소창 주소 전체**를 DM 으로 보내기
4. 아침 브리핑(기본 07:30)이 각자 DM 으로 간다. "브리핑 8시로 바꿔줘", "예약 작업 보여줘" 등은 본인 것만 다룬다
5. 가족 로그인 상태는 관리자 아침 브리핑의 헬스체크(`가족:<이름>`)에 나온다

로그인 메시지(주소·코드)는 대화 기록·세션에 남기지 않는다. 로그인은 DM 에서만, 10분 안에 끝내야 한다.

## 1. 범위

- 사용자: 본인 포함 최대 5명. 가족은 각자 **Gemini Pro(Google AI Pro)** 계정이 있고 Claude 구독은 없다.
- Slack: 기존 워크스페이스에 초대. **개인 비서는 봇과의 DM**, 가족 공용 일은 `#가족` 채널에서 `@agent` 멘션.
  - DM 은 1:1 이라 서로 보이지 않고(무료 플랜은 관리자도 DM 열람 불가), 휴대폰 알림이 기본으로 켜져 리마인드에 유리하다.
  - 대화 이어가기·세션·오염 표시는 이미 DM 채널 기준이라 사람별로 자연스럽게 나뉜다.

## 3. 엔진 배분

| 작업 | 본인 | 가족 |
|---|---|---|
| 대화 (Tier 1) | agy (본인 계정) | agy (각자 계정, 사람별 프로필) |
| `--deep` | claude | 제공 안 함 |
| 일정·메일·알림 요청 해석 (플래너) | claude Haiku (도구 없음) | **agy flash-low + `--json-schema`** (입력이 본인 문장뿐이라 안전) |
| 일정 목록 | Python (LLM 없음) | 같음 |
| 메일 조회 | 도구 없는 claude 가 요약 | **발신자·제목 목록만** (LLM 없음, 메일 감시 알림과 같은 방식) |
| 아침 브리핑 | 헬스체크 + 일정 + 메일 요약 | 일정 + 메일 목록 |
| 문서 색인·OCR | 있음 | 제공 안 함 (가족 문서는 각자 PC) |

**원칙 유지:** 메일 등 외부 텍스트는 agy 에 넣지 않는다 (agy 는 도구를 끌 수 없음 — 0단계 실측).
나중에 가족도 메일 요약이 필요해지면 결제 연결된 Cloud 프로젝트의 Gemini API 키로 "도구 없는 엔진"을 추가한다.

## 4. 구현 내용 (2026-10-28, 계획 1~8 모두 반영)

1. **사용자 목록** `users.yaml`: Slack 사용자 ID → 이름, 역할(owner/family), Vault 폴더, agy 프로필, Google 토큰 경로, 플래너 엔진.
   목록에 없는 사람의 메시지는 무시한다 (`SLACK_ALLOWED_USER_ID` 대체).
2. **사람별 격리**: agy 프로필·bwrap 바인드를 사람별 폴더(`~/Family/<이름>/`)와 공용 폴더(`~/Family/공유/`)로 한정.
   대화 기록(`_Chat_Logs`)도 각자 폴더에 저장한다.
3. **Google**: 토큰을 사람별 파일로, `tools/google.py` 호출에 사용자 컨텍스트를 넘긴다.
4. **예약 작업**: 잡에 소유자를 저장하고 그 사람 DM 으로 보낸다. 목록·취소·브리핑 시각은 본인 것만.
5. **대기열**: 엔진별 1개 → **사람별 대기열**로 바꿔 가족 요청이 서로 기다리지 않게 한다 (계정이 달라 병렬 가능).
6. **승인 버튼**: 요청한 본인만 누를 수 있게.
7. **로그인을 DM 으로**: 봇이 로그인 주소를 보내고, 가족이 리디렉션 주소(Google)·인증 코드(agy)를 DM 으로 답하면 서버가 마무리.
   인증 코드가 채팅 기록에 남지 않도록 처리 후 Slack 메시지를 삭제하거나 대화 기록에서 가린다.
8. **헬스체크·브리핑 경고**: 사람별 토큰·agy 로그인 상태를 점검해 본인에게만 경고.

예상 규모: 1~4·6 반나절, 5·7·8 반나절. 가족 1명 시범 후 나머지 추가 (사람당 10~20분).

## 5. 알려 둘 점

- 서버 관리자(본인)는 기술적으로 가족 데이터에 접근할 수 있다. 시작 전에 가족에게 알린다.
- 서버 한 대가 꺼지면 모두 쓸 수 없다.
- 가족의 Google 연결은 각자 계정의 **보안 → 타사 앱** 에서 언제든 끊을 수 있다.
